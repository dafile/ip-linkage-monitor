# v1.3.0 蓝牙邻近监控版

## 新增：蓝牙监控（与 IP 监控二选一）

- 设置 → 监控方式：「📡 IP Ping 监控」/「🔵 蓝牙邻近监控」一键切换
- 蓝牙模式：按设备名称（包含匹配）或 MAC（精确匹配）判定在线，**手机不连 WiFi、ping 不通也能靠蓝牙在场判定"未掉线"**
- 「🔍 扫描拾取」：扫描附近设备列表，点击即选中目标（显示名称/MAC/连接状态）
- 「🔌 测试蓝牙检测」：即时验证能否发现目标，显示扫描到的设备总数与耗时
- 扫描时长可调（约 2.6 ~ 15.4 秒）；扫描异常（如无蓝牙适配器）自动限流告警并保持原状态，不误触发联动
- 监控方式切换、蓝牙目标修改等全部记录运行日志

## 蓝牙可见性说明（重要）

经典蓝牙查询只能发现：① 与电脑**已配对且保持蓝牙连接**的设备；② 处于**「可被发现」**状态的设备（如手机停在蓝牙设置页）。
多数手机平时息屏时不可被经典蓝牙发现，这是系统级限制。**蓝牙监控最适合与电脑保持蓝牙连接的手机/耳机**，
或选择持续 BLE 广播的设备（手环/手表等）。

## 其他

- 控制台「立即检测」按当前监控方式自动执行（IP ping 或蓝牙扫描）
- 全部 9 个单元测试通过；无蓝牙适配器的机器优雅降级（明确报错提示，不崩溃）
- 配置文件自动向前兼容（新增字段带默认值）

## 下载即用

附件 ip-linkage-monitor.exe 为绿色单文件，双击运行（需 WebView2，Win10/11 一般已内置）。
配置与日志保存在程序目录 data\ 文件夹。
