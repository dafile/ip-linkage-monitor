# v1.5.1 单实例守卫：重复启动聚焦已有窗口

## 问题

程序此前**没有任何单实例约束**：每启动一次就是一个独立进程——
每个实例各自创建托盘图标（托盘出现多个相同图标）、各自运行监控循环
（同一状态变化可能重复执行联动规则），还共用同一份 config.json 与日志文件
（并发写入存在覆盖/交错风险）。

## 修复

- 接入 Tauri 官方 `tauri-plugin-single-instance`（Windows 命名互斥量）：
  - 重复启动的第二个进程**立即自动退出**，不会产生第二个托盘图标；
  - 已运行的实例收到通知后，把窗口**恢复显示并置前**（覆盖"最小化到托盘"状态）；
  - 若 Windows 拒绝前台聚焦，自动闪动任务栏提示；
  - 重复启动事件写入运行日志：「检测到重复启动：已聚焦正在运行的窗口」。

## 实测验证（本机）

- 连续启动 exe 两次：进程数始终保持 **1**，日志出现重复启动记录；
- 窗口最小化到托盘后再启动 exe：主窗口从托盘恢复显示（窗口枚举可见数量 1→2，含标题窗口），进程数仍为 1；
- 16/16 单元测试通过，无回归。

## 下载即用

附件 ip-linkage-monitor.exe 为绿色单文件，双击运行（需 WebView2，Win10/11 一般已内置）。
配置与日志保存在程序目录 data\ 文件夹。

> 升级提示：机器上此前多开的旧实例需要先手动结束一次；换成 v1.5.1 后不会再出现多个托盘图标。
