# v1.4.0 蓝牙监控重构：系统 API 直读（多通道）

## 检测策略（三级通道，任一命中即在线）

1. **系统维持连接**（推荐，已配对 BLE 设备）：程序通过 Windows API
   （GattSession.MaintainConnection + 电池服务通知订阅）让系统持续维持与手机的
   BLE 连接——手机在蓝牙范围内系统就自动连上，离开范围自动断开；直读系统连接状态。
   无需手机可发现、无需连 WiFi、手机端零操作（配对一次即可，耗电极低）。
2. **经典蓝牙连接状态**：已配对设备若有任何经典档案在连接（音频/网络共享等）同样在线。
3. **主动扫描**（兜底，未配对设备）：经典 inquiry，仅「可被发现」设备可见；
   自动排除配对缓存误判（设备关机也不会再显示在线）。

## 修复

- 蓝牙拾取器/测试结果中 "undefined ms"：DTO 字段命名统一为 camelCase
- 已配对 BLE 条目名称为空时（如 "Bluetooth LE Device a4ccb388f111"），自动用
  经典蓝牙配对名称补全（如 "k6u"）——按手机名或 MAC 匹配均可命中
- 电池服务通知订阅：强制系统维持 GATT 连接，比单纯 MaintainConnection 更稳
- 扫描拾取合并显示：经典配对（含名称）+ BLE 配对 + 在场设备，按 MAC 去重

## 使用建议

蓝牙模式下：先点「⚙ 打开系统蓝牙设置」确认手机已配对（经典+BLE 两条都正常），
然后在程序里选该设备（或填 MAC / 手机名），点「测试蓝牙检测」验证。
手机在旁边 → 应显示「系统连接直读：手机在蓝牙范围内」。
