# v1.4.0 蓝牙监控重构：系统 API 直读

## 核心变化

蓝牙检测改为**两级策略**，彻底解决"手机在附近却检不到 / 不在却检到"的问题：

### ① 系统连接直读（推荐，已配对设备）

手机与电脑在系统蓝牙中**配对一次**后，程序通过 Windows API（`GattSession.MaintainConnection`）
让系统持续维持一条低功耗蓝牙连接：

- 手机**在蓝牙范围内** → 系统自动连上 → **在线**（手机息屏、不连 WiFi、无需可发现）
- 手机**离开范围** → 连接断开 → **离线**
- 手机端零操作、无需装任何 App、BLE 维持连接功耗极低
- 直读系统连接状态，不再依赖扫描碰运气

### ② 主动扫描（兜底，未配对设备）

经典蓝牙 inquiry，仅「可被发现」设备可见；自动排除配对缓存误判。

## 配套改进

- 「扫描拾取」同时列出**已配对设备**（🟢已连接 / 🔵已配对，优先展示）与在场设备（⚪）
- 「测试蓝牙检测」明确报告检测模式：系统连接直读 / 主动扫描，并显示绑定的设备
- 新增「⚙ 打开系统蓝牙设置」快捷按钮，引导配对
- 系统维持连接会话常驻复用，切换监控目标时自动迁移
- 12/12 单元测试通过（新增 BLE 设备 ID 解析、汇总扫描冒烟测试）

## 使用建议

蓝牙模式下请先点「⚙ 打开系统蓝牙设置」与手机配对，然后在程序里选该设备——
这就是你要的"只要手机还在附近就算在线"。

## 下载即用

附件 ip-linkage-monitor.exe 为绿色单文件，双击运行（需 WebView2，Win10/11 一般已内置）。
配置与日志保存在程序目录 data\ 文件夹。
