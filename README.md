# 掌上看家联动 IP 在线状态监控

[![Release](https://img.shields.io/github/v/release/dafile/ip-linkage-monitor?label=%E6%88%90%E5%93%81%E4%B8%8B%E8%BD%BD)](https://github.com/dafile/ip-linkage-monitor/releases)

基于 **Tauri 2** 的 Windows 桌面工具（v1.3.0）：实时监控指定目标（**IP Ping** 或 **蓝牙邻近**，二选一）的
在线状态，按**可自由配置的联动规则**在目标上线/离线后延迟执行动作——启动/彻底关闭监控程序、
显示/隐藏窗口，或**自定义执行任意脚本/程序**。支持系统托盘、配置导入导出、完整日志记录与导出。

## 下载成品

无需安装 Rust 环境，直接从 [Releases](https://github.com/dafile/ip-linkage-monitor/releases)
下载 `ip-linkage-monitor.exe`，双击运行即可（需系统自带 WebView2 运行时，Win10/11 一般已内置；
数据保存在程序目录 `data\`，绿色便携）。

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 注册表路径读取 | 默认从 `HKLM\SOFTWARE\Wow6432Node\...\Uninstall\{B659A0AE-...-81EBEBF91321}_is1` 读取掌上看家采集端安装路径（首次启动自动执行），也支持手动浏览选择 |
| IP 在线监控 | 默认监控 `172.30.109.238`，可在设置中修改；系统 `ping` 检测（TTL 校验，避免"不可达"误判为在线） |
| **蓝牙邻近监控** | 与 IP 监控**二选一**（设置中切换）。**两级策略**：<br />① **系统连接直读（推荐）**：手机与电脑在系统蓝牙中配对一次后，程序通过 Windows API（`GattSession.MaintainConnection`）维持一条低功耗蓝牙连接——**手机在蓝牙范围内系统就自动连上，离开范围自动断开**，直读系统连接状态即"在不在附近"。无需连接 WiFi、无需手机可发现、手机端零操作、耗电极低；<br />② **主动扫描（兜底）**：未配对设备走经典蓝牙 inquiry，仅「可被发现」设备可见；自动排除配对缓存误判（v1.3.1）。<br />支持「扫描拾取」（已配对设备优先展示）、「测试蓝牙检测」（报告检测模式）、「打开系统蓝牙设置」快捷入口 |
| 监控方式切换日志 | 切换监控方式、修改蓝牙目标等全部记录在运行日志；扫描异常（如无蓝牙适配器）自动限流告警并保持原状态不误触发联动 |
| 联动规则引擎 | 每条规则 = **触发时机**（IP 上线/离线）+ **延迟秒数**（0=立即，任意可调，附快捷选项）+ **动作** + **备注** + 独立启用开关；规则数量不限，同一状态变化可并行触发多条；联动总开关一键停用全部 |
| 规则原子保存 | 新增/修改/删除/启停均逐条**即时提交后端**（不存在整份覆盖导致的丢规则问题）；试运行直接使用界面当前的动作配置，不依赖保存状态 |
| 内置动作 | 启动监控程序 / 彻底关闭监控程序（含守护进程防复活）/ 显示窗口 / 隐藏窗口 |
| 自定义动作 | 「执行脚本/程序」：选择 `.bat` / `.cmd` / `.ps1` / `.exe` 并可填启动参数；自动选择宿主（ps1→powershell，bat/cmd→cmd），可勾选"隐藏窗口运行"；以脚本所在目录为工作目录 |
| 试运行 | 每条规则可「▶ 试运行」立即执行一次，方便调试脚本 |
| 彻底关闭 | 采集端为互拉守护架构（主程序 ↔ AvsLoader 互相拉起），关闭时同时结束同目录守护进程并做 15 秒防复活验证 |
| 系统托盘 | 左键单击显示主窗口；右键菜单：显示主窗口 / 联动开关（与界面双向同步）/ 彻底关闭监控程序 / 退出程序 |
| 关闭行为 | 默认**关闭窗口 = 最小化到托盘**（后台继续运行）；可在设置中改为"关闭即退出" |
| 便携化存储 | 全部配置与日志存放在**程序所在目录 `data\`**（`config.json` + `logs\`），绿色便携；目录不可写时自动回退 `%APPDATA%`；旧版本配置自动迁移 |
| 导入/导出配置 | 设置 → 通用设置：导出为 JSON 备份文件，导入后覆盖全部设置与规则（带校验与确认） |
| 日志系统 | 按天记录（JSON Lines）：系统 / 监控 / 操作 / 配置 四类；日期、级别、类别、关键词筛选，实时刷新，导出 CSV（带 BOM），一键清空 |
| 设置持久化 | 基础设置串行保存队列（保存期间的新修改排队重发，绝不丢失），底部保存栏实时显示"未保存更改/已保存"状态，并提供显式「💾 保存配置」按钮 |

## 默认联动规则（首次启动自动生成，可随意修改）

1. IP **上线** 10 秒后 → **彻底关闭监控程序**
2. IP **离线** 10 秒后 → **启动监控程序**

> 策略方向可在设置页自由调整（任何 触发×延迟×动作 组合），删光规则后不会自动再生；
> 设置页提供「恢复默认规则」一键还原。

## 蓝牙监控的使用要点

**推荐（系统 API 直读）**：在 Windows 蓝牙设置中把手机与电脑**配对一次**（设置页有快捷入口按钮），
之后程序会让 Windows 自动维持一条低功耗蓝牙（BLE）连接：

- 手机**在蓝牙范围内** → 系统自动连上 → 判定**在线**（手机息屏、锁屏、不连 WiFi 都没关系）
- 手机**离开蓝牙范围**（约 10~30 米，视环境）→ 连接断开 → 判定**离线**
- 手机端无需任何 App、无需保持「可被发现」、BLE 维持连接功耗极低

**兜底（主动扫描）**：目标未与电脑配对时，退回经典蓝牙查询。只有处于「可被发现」状态的设备
（如手机停在蓝牙设置页）才能被听到；结果中的配对缓存条目（设备关机也会出现）会被自动排除，
只有本轮真实听到或当前已连接的设备才计为在场。

多数手机平时息屏不可被经典蓝牙发现，这是 Android/iOS 的系统级限制——所以**强烈建议走配对直读方案**。

## 联动引擎语义

- 程序启动后的**首次检测结果只记录不联动**；之后每次状态变化触发对应规则。
- 延迟倒计时期间 IP 状态再次反转 → 与新状态不符的待执行任务自动作废（也可在控制台手动取消单条或全部）。
- 同一条规则重复触发不会重复排队；多条不同规则可同时排期、并行执行。
- 规则执行（含成功/失败与脚本退出）全部写入运行日志，备注会出现在日志与控制台摘要中。

## 构建与运行

依赖：Rust 1.77+（MSVC 工具链）、WebView2 运行时（Win10/11 一般自带）。无需 Node。

```bash
cd src-tauri
cargo build --release          # 产物：target/release/ip-linkage-monitor.exe
cargo test --release           # 6 个单元测试（规则调度/脚本执行/进程控制/真实采集端彻底关闭）
```

直接运行 `ip-linkage-monitor.exe` 即可（绿色单文件，界面资源已内嵌）。

- 配置文件：`<程序所在目录>\data\config.json`（规则即 JSON 数组，可手改；目录不可写时回退 `%APPDATA%\com.athome.ipmonitor\`）
- 日志目录：`<程序所在目录>\data\logs\log-YYYYMMDD.jsonl`
- 托盘：关闭窗口默认最小化到托盘，托盘右键菜单可退出；可在设置中修改关闭行为

## 常见问题

- **显示窗口提示"未找到可显示的窗口"**：监控程序可能以纯托盘方式运行，或尚未启动。
- **关闭失败（权限）**：若监控程序以管理员身份运行，本程序也需以管理员身份运行。
- **脚本没执行**：试运行看报错；`.ps1` 以 `-ExecutionPolicy Bypass` 运行；路径含空格无需手动加引号（选择文件自动填入）。
- **开机后采集端自己启动了**：厂商写入的开机自启（`HKCU\...\Run` 下 `AtHomeVideoStreamer /s`），
  与本程序无关；可在任务管理器 → 启动应用 中禁用。
